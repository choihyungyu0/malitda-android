# 말잇다 개발 노트 (2026-09-21 기준, 초안)

> 별첨3 「개발 노트」 양식의 1·2·3 항목에 그대로 옮겨 쓸 수 있게 정리했다. 숫자는 이 문서에 적힌 조건에서만 유효하며, **실기기 측정값은 아직 없다.**

## 1. 주요 개발 내용

### 1.1 구현 범위(알파 APK)

- 화면 계약 S01~S27 전부 구현(온보딩 4 · 표현 등록 3 · 홈 · 말하기~공유 6 · 표현 관리 3 · 교정 이력 · 예외 4 · 설정 · 리워드 2).
- 핵심 흐름: **원문 보존 → 후보 선택(자동 선택 없음) → 확인·수정(들어보기) → 승인(체크) → 공유(시스템 공유/복사/문자) → 복귀(S26)**.
- 승인 게이트: 승인 토큰 = 승인 시점 문장의 SHA-256. 후보 변경·직접 수정·재발화로 문장이 한 글자라도 바뀌면 공유 버튼이 즉시 잠긴다. 미승인 문장은 어떤 경로로도 외부로 나가지 않는다.
- M1 개인 교정(신경망 학습 아님): 승인 시 `정규화(원문) ≠ 정규화(승인문)`이면 (사용자, 정규화 원문) → 승인문 쌍을 저장. 다음 인식에서 **규칙1** 원문이 저장한 오인식과 완전히 같을 때만 승인문을 후보 맨 앞에 제시, **규칙2** 인식기가 실제로 낸 복수 후보 안에 승인문이 있을 때만 순서 이동. 유사도·편집거리는 쓰지 않는다. 개별 삭제·전체 초기화 시 기본 인식 결과로 복원(에뮬레이터에서 확인).
- 정규화 3규칙(NFC·연속 공백·문장 끝 부호)과 **문장 정리 규칙**(비발화 토큰 제거, 형태소 단위로 띄어진 조사·어미를 앞 어절에 1회 결합)은 모든 엔진·모든 조건에 동일 적용.
- 저장: Room + SQLCipher(무작위 32바이트 키를 Android Keystore AES-GCM으로 감싸 보관). DB 파일 헤더가 평문 SQLite가 아님을 확인. 사용자별 분리(프로필), 백업 제외.
- 개인정보: 인터넷 권한 없음(매니페스트에 INTERNET 미선언) · 원음성 파일 미저장 · 인식 문장 로그 미기록 · 공유 이력·상대방 미저장 · 설정 화면에 앱 송수신량(TrafficStats) 실시간 표시(현재 0 B).
- 접근성: 모든 터치 대상 48dp 이상, 시스템 글자 크기 200%에서 전 화면 확인(홈 마이크 라벨·카테고리 칩은 자동 축소 처리), 진동 알림·시각 강조(읽어주는 단어 하이라이트)·읽어주는 속도 설정, TalkBack용 콘텐츠 설명·라이브 리전 부여(실기기 TalkBack·Switch Access 검증은 미실시).
- TTS: 시스템 TextToSpeech에서 한국어 오프라인 음성을 우선 선택하고 설정에 엔진·음성·오프라인 여부 표시. 음성 불가 시 S24로 대체.

### 1.2 로컬 STT — 수정 전 기준선 두 개를 같은 앱에 탑재

| | Vosk `vosk-model-small-ko-0.22` | whisper.cpp `ggml-base-q5_1` |
|---|---|---|
| 방식 | 스트리밍(Kaldi), 부분 결과 표시 | 비스트리밍, 중지 후 일괄 인식 |
| 복수 후보 | 3개(N-best) → M1 규칙2 동작 | 없음 → M1 규칙1만 동작 |
| 모델 크기(단말 저장) | 252 MB | 57 MB |
| 모델 불러오기 | 3.2~4.2 s | 0.8 s |
| 프로세스 메모리(PSS, 에뮬레이터) | **약 604~617 MB** | **약 241 MB** |
| 출력 특성 | 형태소 단위 띄어쓰기, `[2]` 같은 비발화 토큰 | 문장부호 포함, 무음에서 환각 가능 → 무음 게이팅·no_speech 확률 필터 적용 |

설정 화면에서 엔진을 전환하면 이전 모델을 내리고 새 모델을 불러온다(한 번에 하나만 메모리에 둠).

### 1.3 사전 비교 결과(합성음, 에뮬레이터) — **실기기 측정 전**

조건: Windows SAPI 한국어 합성음(Heami) 6문장, 16 kHz mono WAV, 같은 문장 정리 규칙, Android 에뮬레이터(x86_64, 4코어). 앱 내 "전체 음원 평가 실행"으로 산출, `files/eval/*.csv`.

| 지표 | Vosk small-ko | whisper.cpp base-q5_1 |
|---|---|---|
| 평균 CER | 39.4 % | **0.0 %** |
| 평균 WER | 82.8 % | 11.1 % (띄어쓰기 차이 1건) |
| 문장 완전일치 | 1/6 | 5/6 |
| 무응답 | 0/6 | 0/6 |
| 처리시간(파일 일괄 디코딩) | 2.1~2.6 s / 발화 1.8~3.3 s | 35 s → **약 10 s** (에뮬레이터, `audio_ctx` 384~) |

해석 범위: 합성음은 조음이 또렷한 낭독체이므로 구음장애·비정형 발화의 성능을 대변하지 않는다. 다만 같은 조건에서 Vosk small-ko의 어휘·언어모델 한계(형태소 분절, 고유명사·구어 표현 오인식)가 분명해, **A(기준모델)는 whisper.cpp 계열을 우선 검토**한다. Whisper의 처리시간은 x86 에뮬레이터(ARM NEON 경로 아님)에서 잰 값이라 단말 성능을 대변하지 않으며, 실기기 2종에서 "시험 음원 95% 이상을 발화 길이 이내 처리" 기준으로 다시 잰다.

Whisper 관련 결정론적 처리(모든 조건 동일): ① 인코더 창(`audio_ctx`)을 발화 길이+2초로 줄이되 하한 384(≈7.7초) 유지 — 256까지 줄였을 때 짧은 발화에서 같은 문장이 두 번 나오는 반복 출력이 생겨 하한을 올렸다. ② 직전 세그먼트와 완전히 같은 세그먼트는 한 번만 남긴다(디코더 반복 아티팩트). ③ 무발화 확률 0.6 초과 세그먼트 제외, 발화 에너지 프레임 4% 미만이면 무응답.

## 2. 제안서(중간심사) 대비 변경사항 및 사유

| 항목 | 제안서 | 변경 | 사유 |
|---|---|---|---|
| STT 엔진 | Vosk small-ko·Whisper base를 사전 비교 후 A 선정 | **두 엔진을 같은 APK에 탑재해 앱 안에서 전환·비교** | 같은 단말·같은 음원·같은 정리 규칙으로 비교해야 공정. 데스크톱 비교만으로는 Android 실행성(속도·메모리)을 알 수 없음 |
| 문장 정리 규칙 | "같은 문장 정리 규칙" 언급 | 구체화: 비발화 토큰 제거 + 조사·어미 1회 결합 | Vosk 출력이 형태소 단위(`학교 에 가 고`)라 그대로 보이면 읽기·TTS가 어색함. 결정론적 규칙만 쓰고 단어를 바꾸지 않음 |
| Top-3 | 실제 복수 후보 엔진에만 적용 | 동일. Whisper 조건에서는 M1 규칙2가 동작하지 않음을 명시 | Whisper는 N-best를 내지 않음 |
| 무응답 판정 | 인식기 무결과 | Whisper는 **무음 게이팅**(20 ms 프레임 RMS) + 세그먼트 no_speech 확률 필터로 무응답 처리 | Whisper는 무음에서 문장을 지어내는(환각) 특성이 있어 그대로 두면 무응답률이 왜곡됨 |
| 로컬 암호화 | Room/DataStore, 로컬 암호화 | SQLCipher + Keystore 로 실제 구현 | 문구와 구현 일치 |
| 최근 사용 문장(홈) | 디자인 원안 "최근 사용 문장" | "최근에 등록한 표현"으로 대체(화면 계약 S08과 동일) | 전송 문장은 저장하지 않는다는 방침 |
| 리워드(S19·S20) | P1 조건부 | 구현하되 **기본 꺼짐**, 접근성 설정에서 켬. 횟수만 세고 문장 내용은 저장하지 않음 | 원안 보존 + 방침 준수 |
| 공유 취소 감지 | S26 "공유 취소/복귀" | 취소 여부는 감지하지 않고, 공유 화면에서 돌아오면 항상 문장·승인 상태 유지 | Android 공유 시트는 취소 결과를 앱에 돌려주지 않음 |
| 모델 배포 | (미정) | 두 모델 모두 APK 동봉, 첫 실행 시 앱 전용 저장소로 복사 | 비행기 모드 첫 실행·송수신 0 요건 |

## 3. 기타 이슈 및 보고 사항

- **APK 용량**: 디버그(3 ABI, 두 모델) 230 MB. 제출용(arm64·armeabi-v7a, R8)은 약 180 MB 예상. 이메일 첨부 한도를 넘으므로 대용량 첨부 링크로 제출.
- **메모리**: Vosk 조건 PSS 약 600 MB는 저사양 단말에서 위험. 실기기 측정 후 Vosk를 기본에서 제외할 수 있음.
- **미검증**: 실기기(삼성 1 + 비삼성 1)에서 마이크 경로·TTS 오프라인 음성·비행기 모드·처리시간·발열, TalkBack·Switch Access 완주, 200% 확대 실기기.
- **M0(AI-Hub 608 구음장애 데이터 공통 모델)**: 미착수. Whisper 계열을 A로 정하면 M0는 Whisper 파인튜닝 → ggml 변환으로 같은 실행기에 그대로 교체 가능(`assets/whisper/*.bin`).
- **실증 준비물**: 참여자 3~5명 동의서(보호자·본인), 과업 5건(메시지 2·검색 2·고유명사 1), 실기기 2종, 평가용 음원 녹음 절차(같은 음원을 A/B/C에 사용).
- **재현**: 앱 전용 폴더 `files/testaudio/`에 WAV + `refs.txt`를 넣고 설정 → 전체 음원 평가 실행 → `files/eval/*.csv`.
